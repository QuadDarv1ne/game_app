## 📋 Описание проекта

**GameApp** — это интерактивный игровой блог, созданный на основе фреймворка Laravel с использованием Livewire для динамического интерфейса. Платформа позволяет авторизованным пользователям создавать, редактировать и удалять посты, добавлять теги и оставлять комментарии. Гости могут просматривать публикации без регистрации.

### 🛠 Технологии

| Компонент | Технология |
|-----------|-----------|
| **Фреймворк** | Laravel 11 |
| **Бэкенд** | PHP 8.5.0 |
| **Frontend** | Livewire + Blade Templates |
| **База данных** | MySQL 8.4.7 |
| **Авторизация** | Laravel Breeze |

## ✨ Функциональные возможности

### 🔐 Авторизация и управление аккаунтом
- Регистрация и вход пользователей (Laravel Breeze)
- Просмотр и редактирование профиля
- Удаление аккаунта

### 📝 Посты (CRUD)
- Создание, просмотр, редактирование и удаление постов
- Привязка постов к автору — только владелец может редактировать или удалять свой пост
- Пагинация списка постов
- Просмотр доступен всем, включая неавторизованных гостей

### 🔍 Поиск и фильтрация
- Поиск по заголовку, тексту и описанию поста
- Фильтрация по категориям и тегам
- Сортировка: по дате, популярности, алфавиту
- Отображение активных фильтров

### 🏷 Система тегов
- Привязка тегов к постам через связанную таблицу
- Организация контента по категориям

### 💬 Комментарии
- Создание, редактирование и удаление комментариев
- Привязка комментариев к пользователям и постам
- Полноценный CRUD для каждого поста

### ⭐ Избранное (Bookmarks)
- Добавление постов в избранное одним кликом
- Управление избранным через Livewire компонент
- Счётчик отметок для каждого поста
- Персональная страница избранного в профиле

### 👤 Профиль пользователя
- Статистика: количество постов, комментариев, избранного
- Вкладки: посты пользователя / избранное
- Аватар с инициалами пользователя
- Просмотр профилей других пользователей

## 🚀 Установка и запуск

### 1. Настройка окружения

Скопируйте файл `.env.example` в `.env` и настройте параметры:

```bash
cp .env.example .env
```

- Укажите адрес вашего URL
- Настройте подключение к базе данных
- Сгенерируйте ключ шифрования:

```bash
php artisan key:generate
```

### 2. Миграция базы данных

```bash
php artisan migrate
```

### 3. Заполнение базы данных (опционально)

```bash
php artisan db:seed
```

### 4. Установка и сборка фронтенда

```bash
npm install
npm run build
```

### 5. Запуск сервера

```bash
php artisan serve
```
